metanalisys v0.1.0-alpha.9 - Windows portable
================================================

Avvio
-----

1. Estrarre completamente lo ZIP.
2. Aprire la cartella estratta.
3. Eseguire metanalisys.exe.

Non e' richiesta un'installazione di Python.

Stato del software
------------------

metanalisys v0.1.0-alpha.9 e' ancora software in fase Alpha.
Usarlo solo come supporto tecnico preliminare e in contesti autorizzati.

Limiti
------

Il software:

- fornisce supporto tecnico all'analisi preliminare dei metadati;
- non costituisce da solo una prova;
- non sostituisce procedure autorizzate;
- non sostituisce catena di custodia;
- non sostituisce valutazione professionale.

Privacy
-------

Dall'analisi del codice di questa versione risulta che il software opera
localmente sui file selezionati dall'utente, non introduce telemetria e non
invia automaticamente documenti o risultati a servizi esterni.

I report eventualmente salvati vengono scritti nella posizione scelta
dall'utente.
